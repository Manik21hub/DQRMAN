# DQRMAN — Distributed Quantum-Resistant Mesh Authentication Network

A decentralized, post-quantum cryptographic authentication system 
designed to secure military IoT devices, autonomous drone swarms, 
and tactical edge networks against both classical and quantum 
computing threats.

## The Problem
- Classical military networks (RSA/ECC) will be broken by quantum computers
- Centralized authentication = single point of failure
- GPS spoofing and jamming compromise autonomous systems
- No current standard exists for quantum-safe mesh authentication

## The Solution
DQRMAN replaces centralized authentication with a self-organizing, 
quantum-resistant mesh where every device is its own trust node.

## Core Components
- CRYSTALS-Dilithium post-quantum signatures (NIST-approved)
- Distributed trust mesh — no central server required
- Temporal-spatial authentication (UWB proximity + time-sync)
- Self-healing routing when nodes are destroyed or compromised
- Zero-trust architecture — every device verifies every device
